IMAGES FOLDER
=============

Add the school photograph here with this exact file name:

    hero.jpg

Used on the Home page (index.html) as the main hero photograph.

Guidance:
- Use a photo the school has permission to publish.
- Do not label students by name in captions unless the school has
  approved that for publication.
- Keep the file reasonably small (about 1600px wide, under 300 KB)
  so the page loads quickly.

If the file is missing, the Home page automatically shows a
placeholder box instead — nothing breaks.
